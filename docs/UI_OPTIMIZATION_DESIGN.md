# VideoEye 2.0 UI/UX 优化设计稿

> 设计文件：`VideoEye UI Optimization`（Ardot 画布）  
> 更新日期：2026-07-05  
> 适用范围：Qt6 + FFmpeg 视频流分析工具的主界面重构  

---

## 1. 设计目标

基于现有代码结构（`MainWindow` + `AnalysisPanel` 11 个分析模块），本次优化聚焦于：

1. **信息层级重构**：把原本横向堆叠的 10 个分析 Tab 迁移到左侧垂直导航，释放顶部空间并提升可扩展性。
2. **视觉风格统一**：采用深色专业风格（Dark First Pro），降低长时间分析的视觉疲劳。
3. **关键数据突出**：用卡片、微图表、状态徽标等手段，让 FPS、码率、关键帧、容器结构等信息一眼可读。
4. **交互语义清晰**：播放控制、进度条、侧边栏选中态、分析面板开关等控件使用一致的反馈语言。

---

## 2. 整体布局

```
┌─────────────────────────────────────────────────────────────┐
│  Top App Bar  (Logo / 文件名 / 主要操作)                      │
├──────────┬──────────────────────────────────────────────────┤
│          │  Video Display Area                                │
│  Left    │  (分辨率 / 编码 / FPS / 状态叠加层 + 中央播放按钮)  │
│ Sidebar  ├──────────────────────────────────────────────────┤
│ (分析导航)│  Control Bar (播放/停止/进度/时间/音量)            │
│          ├──────────────────────────────────────────────────┤
│          │  Analysis Panel (当前选中分析模块的内容区)         │
├──────────┴──────────────────────────────────────────────────┤
│  Status Bar (状态 / 实时指标 / 当前时间)                      │
└─────────────────────────────────────────────────────────────┘
```

- 默认窗口尺寸保持 `1200×800`（与现有代码一致），设计稿按 `1440×900` 绘制以预留大屏适配空间。
- 左侧边栏宽度 `200px`，与主内容区分隔采用 `1px #30363D` 细线，不使用投影。

## 3. 色彩系统（GitHub Dark）

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景色 | `#0D1117` | 最底层画布 |
| 卡片/面板 | `#161B22` | 边栏、控制栏、分析面板 |

## 5. 组件细节

### 5.1 Top App Bar（高度 48px）

- **左侧**：Logo 图标 + `VideoEye` + 版本徽标 `2.0`（蓝色底 `#58A6FF` 15% 透明度）。
- **中间**：当前媒体路径 `JetBrains Mono 13px`，居中对齐，路径过长时显示省略号。
- **右侧**：
  - `打开文件`：主按钮，蓝色填充 `#58A6FF` 12% 透明度 + 蓝色边框。
  - `打开URL`、`导出帧`：次级按钮，灰底 `#21262D`。
  - `设置`：图标按钮（三点）。

### 5.2 Left Sidebar（宽度 200px）

- 分组标题：`分析功能`（11px，弱化色）。
- 导航项：图标 + 标签，高度 34px，圆角 6px，间距 10px。
- **选中态**：
  - 背景 `#58A6FF` 8% 透明度。
  - 左侧 3px 蓝色高亮条（y: 8, h: 18, r: 2）。
  - 文字变白 + 图标变蓝。
- **未选中态**：无背景，文字/图标为 `#8B949E`，hover 时背景 `#21262D`。

导航项列表（与现有 `AnalysisPanel` 11 个分析模块对应）：

1. 媒体信息（默认选中）
2. 流分析
3. 视频帧
4. 音频帧
5. 数据包
6. 异常事件
7. 同步分析
8. 时间轴
9. 音频响度
10. 直方图
11. 容器结构

> 实现提示：用 `QListWidget` / `QTreeWidget` 或自定义 `QWidget` 列表实现；选中切换时发送信号给分析内容区。

### 5.3 Video Display Area

- 背景 `#01060E`，视频内容居中缩放（保持比例）。
- **叠加信息条**（顶部，内边距 14px）：
  - 左侧：分辨率 `1920×1080` + 编码 `H.264`。
  - 右侧：`30 fps` + `播放中`（绿色）。
  - 徽章背景使用半透明黑 `#000000` 40% 透明度，圆角 6px。
- **中央播放按钮**：
  - 直径 72px 圆形。
  - 背景 `#58A6FF` 12% 透明度 + 边框 `#58A6FF` 30% 透明度。
  - 图标：蓝色三角，居中。
  - 播放时隐藏/半透明，暂停/未播放时显示。

> 实现提示：`VulkanVideoWidget` 中可在 `paintEvent` 或作为子控件叠加；叠加层使用 `QWidget::setAttribute(Qt::WA_TransparentForMouseEvents)` 避免遮挡鼠标。

### 5.4 Control Bar（高度 56px）

- 背景 `#161B22`，与视频区用 1px `#30363D` 分隔。
- **左侧**：
  - 播放/暂停：圆形主按钮 `#58A6FF`。
  - 停止：方形灰底按钮 `#21262D`。
- **中间**：
  - 进度条轨道高 4px，圆角 2px。
  - 已播放部分 `#58A6FF`。
  - 滑块 thumb 直径 12px，白色 `#F0F6FC`。
- **右侧**：
  - 时间 `00:00:12 / 00:00:30`，JetBrains Mono 13px。
  - 音量图标按钮。

> 实现提示：可基于 `QSlider` 自定义样式表；thumb 用 `::handle` 子控件，轨道用 `::sub-page` / `::add-page`。

### 5.5 Analysis Panel

- 背景 `#0D1117` 或 `#161B22`，顶部内边距 12px，左右 16px。
- **面板头部**：
  - 左侧标题（如 `流分析`、`容器结构`），14px SemiBold。
  - 右侧状态徽标 `已启用`：绿色底 `#3FB950` 12% 透明度 + 绿色文字。
- **内容区根据选中模块变化**：
  - **流分析**：3 个统计卡片（FPS / 码率 / 关键帧）+ 两个微图表（码率走势、帧率走势）。
  - **容器结构**：可展开/折叠的树形列表，展示 MP4 box 层级。

#### 统计卡片

- 背景 `#161B22`，圆角 6px，内边距 12px。
- 数值 20px Bold，标签 11px Regular 灰色。

#### 微图表

- 卡片背景，标题 12px 灰色。
- 折线：主色 `#58A6FF`（码率）/ 绿色 `#3FB950`（帧率）。
- 不填充面积，仅描边，保持轻盈。

#### 容器结构树

- 树节点行高 26-28px。
- 展开/折叠图标：`▾` / `▸`。
- Box 类型图标：`◆` 容器 / `◇` 叶子。
- 视频 track 用绿色标记，音频 track 可用 `#58A6FF` 蓝色。
- 缩进每级 24px。

> 实现提示：容器树使用 `QTreeWidget`；自定义 `QStyledItemDelegate` 可精确控制颜色、图标和缩进。

### 5.6 Status Bar（高度 28px）

- 背景 `#161B22`，顶部 1px 分隔线。
- 左侧：状态点（绿 `#3FB950`）+ 播放状态 + 实时指标（FPS / 码率 / 关键帧）。
- 右侧：当前时间 `JetBrains Mono 11px`。

## 6. 交互说明

| 交互 | 行为 |
|------|------|
| 点击侧边栏项 | 切换选中态，分析面板加载对应模块内容，视频区不变。 |
| 点击播放/暂停 | 中央按钮切换图标，状态栏文字同步变化。 |
| 拖动进度条 | 时间码实时更新，视频帧同步 seek。 |
| 点击分析面板开关 | 面板可折叠/展开，释放视频区空间。 |
| Hover 导航项 | 未选中项显示 `#21262D` 背景。 |
| Hover 按钮 | 主按钮背景加深，次级按钮背景变亮。 |

## 7. 与现有代码的对应关系

| 设计区域 | 现有代码位置 | 建议改动 |
|----------|--------------|----------|
| Top App Bar | `MainWindow::SetupUI` 中的 menu/toolbar | 用自定义 `QWidget` 替换默认 toolbar，保持统一风格。 |
| Left Sidebar | `AnalysisPanel` 中的 `QTabWidget` | 将 `QTabWidget` 改为左侧垂直导航列表（11 个模块），内容区改为 `QStackedWidget`。 |
| Video Display | `VulkanVideoWidget` | 在 widget 上叠加信息层和中央播放按钮。 |
| Control Bar | `MainWindow` 底部控制区 | 重绘进度条和按钮样式。 |
| Analysis Panel | `AnalysisPanel` 各 Tab 创建逻辑 | 保留原有数据模型，仅调整展示层。 |
| Status Bar | `QStatusBar` | 用自定义 widget 替换默认 statusbar 内容。 |

## 8. 落地优先级建议

1. **P0 - 布局改造**：左侧导航 + 主内容区结构，替换 `QTabWidget`。
2. **P0 - 深色主题**：定义全局调色板，所有控件接入 `QSS`/`QPalette`。
3. **P1 - 控件重绘**：播放按钮、进度条、状态徽标。
4. **P1 - 叠加信息层**：视频区分辨率/FPS/状态显示。
5. **P2 - 微图表**：码率/帧率趋势图（可复用 `QChartView`）。
6. **P2 - 容器结构树**：用 `QTreeWidget` 实现可折叠 box 树。
